View on GitHub Original Repo npm

✨ What's New in this Fork

  • ✦ Color Engine Injection: Successfully injected a dynamic RGB color engine into the minified WebGL context to preserve orb depth and shading.
  • ✦ Dynamic React Props: The color prop is fully threaded through the render tree so you can switch colors at runtime without unmounting.
  • ✦ Interactive Palette: Built-in parsers let you pass any HEX string, named color, RGB, or HSL value directly to the component.
  • ✦ Light Mode UI: A clean new visual playground to test real-time color syncing.
